# EBI_project
Network-based prioritization of RAS paralog regulatory modules in pan-cancer by seeding network propagation with differential expression signals.

This repository provides a reproducible workflow to prioritize regulatory modules associated with RAS paralogs in pan-cancer cohorts. We start from a high-confidence protein interaction network and use gene expression–derived signals (e.g., differential expression scores) as seeds for network propagation/diffusion. This strategy amplifies coherent perturbations in the interactome and enables the identification of paralog-specific neighborhoods, ranked candidate regulators, and module-level summaries for mechanistic interpretation and downstream validation.
